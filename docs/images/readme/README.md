# README screenshots

Captured from the production UI on September 24, 2026, at a 1440 px desktop width.

- `upload.png`: a validated CSV with a preview of its posts.
- `clean.png`: lowercasing and tokenization selected for demonstration.
- `analyze.png`: before/after metrics and the records table.
- `review.png`: the manual review controls.
- `export.png`: download formats, an editable CSV filename, and checkpoint status.

The capture used 520 synthetic posts from the accessibility audit's sample generator, a separate
local API, and temporary storage. Sentiment responses were deterministic test fixtures; the
numbers are not results from a live Amazon Comprehend run. No collected X posts or credentials
are included.

Images are browser captures of the application, without compositing or generated UI elements.
The repository README supplies descriptive alt text for each image.
